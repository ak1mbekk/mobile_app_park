# mobileappmapmodule

## Мобильный показ «Домик у тропы» · ветка 2.0

### Меню вкладки «Парк»

Пункты для двух режимов посещения хранятся в `src/park-menu.tsx`. Компонент и его стили находятся в `src/components/ui/menu-vertical.tsx` и `menu-vertical.css`. Каталог соответствует алиасу shadcn `@/components/ui`. Общие стили оболочки Tailwind подключены в `src/index.css`.

До визита фотография енота открывает его карточку. В режиме «Я в парке» на этом месте появляется текущее или ближайшее кормление по программе на сегодня в часовом поясе Минска. Нажатие открывает выбранное событие и переход к вольеру. Когда программа закончилась, недоступна или пуста, здесь можно найти зубра на схеме. [Мобильные экраны двух режимов](docs/showcase/park-editorial.jpg)

`npm run menu:build` обновляет комплект меню для статического показа и офлайн-путеводителя. При `npm run dev` и `npm run build` этот шаг выполняется автоматически.

### Карта территории и настройка масштаба

«Я в парке → Карта» открывает карту Leaflet с географической подложкой OpenStreetMap. Нажатие на номер показывает животных и ссылку на ту же точку в Яндекс Картах. Переключатель вверху открывает виджет Яндекса или технический план. Для прогулки без сети заранее сохраните путеводитель в разделе схем. Яндекс использует собственные значки, номера и подписи WC доступны на интерактивном плане и карте Leaflet.

Сверены 54 номера вольеров в двух зонах по печатной нумерации и русской легенде от 12.11.2025. Пять точек WC взяты из OpenStreetMap. Это снимок размещения животных. На территории возможны изменения. Печатная схема используется для расшифровки номеров. Земные координаты рассчитываются по единой привязке технического растра. [Источники и точность](specs/animal-park/maps/alignment.md)

Для ручной настройки запустите из корня проекта `npm run dev -- --host 127.0.0.1 --port 8141` и откройте [редактор совмещения](http://127.0.0.1:8141/demo/align.html). Совместите берега и перекрёстки, переключитесь между зонами для проверки и нажмите «Сохранить для всех». Редактор атомарно записывает новую ревизию в `public/demo/map-alignment.json`. Локальный путеводитель читает файл при открытии карты. Для распространения сохранённого результата файл входит в следующую сборку. Запись доступна только на компьютере с запущенным локальным редактором.

[Запись прохождения на 32 секунды](docs/showcase/Animal-Park.mp4) · [Экраны игры и парка](docs/showcase/showcase.jpg) · [Техническое задание](specs/animal-park/TZ.md)

### Показ путеводителя

Оформление мобильного путеводителя следует [палитрам ветки main ZooKeeper](https://github.com/Animal-Park/zookeeper2v/blob/134532eeea90c9250488f76d25d68d4675e8722b/web/src/index.css) и [карточке животного](https://github.com/Animal-Park/zookeeper2v/blob/134532eeea90c9250488f76d25d68d4675e8722b/web/src/components/AnimalCard.jsx). Шрифт IBM Plex Sans входит в сборку. Темы переключаются на главной парка. [Экраны в светлой и тёмной темах](docs/showcase/visitor-themes.jpg)

Откройте «Карта парка» и нажмите «Сохранить для прогулки без связи», чтобы загрузить обе схемы и каталог с фотографиями. Полное сохранение доступно на localhost и HTTPS. При открытии по обычному HTTP на телефоне можно скачать изображения зон по отдельности. При сбое загрузки расписания приложение показывает последнюю доступную копию и её дату. Расписание работает с локальной публичной выгрузкой. Пустой массив в `byDate[YYYY-MM-DD]` означает день без опубликованных событий, а отметка `status: "cancelled"` исключает напоминания об отменённом кормлении.

Прямая ссылка при локальном запуске — `http://127.0.0.1:8138/#park`. Выберите «Я в парке» → «Кормления» → «Еноты-полоскуны» → «Показать место на схеме». Метка № 54 открывает карточку енота. Обе схемы можно двигать и масштабировать. Для выбора мелкого объекта доступен список под картой. [Экраны работающего путеводителя](docs/showcase/park-guide.jpg)

На схемах двух зон отмечены 37 объектов инфраструктуры. Фильтр «Инфраструктура» помогает найти кафе, корм, место отдыха, туалет, рукомойник или парковку. Ссылка на выбранное место сохраняет зону и фильтр. Номера 54 вольеров сопоставлены с техническим планом. Пиктограммы на иллюстрированных схемах дают положение на рисунке. Пешеходный маршрут в Яндексе открывается при наличии отдельно сохранённой координаты подхода. [Экраны карт](docs/showcase/park-maps.jpg)

В разделе «Как доехать» у каждой зоны своя карточка организации в Яндекс Картах. Посетитель выбирает зону, затем строит маршрут. Фактическое положение входных ворот требует подтверждения парком. [Парк животных](https://yandex.by/maps/org/park_zhivotnykh/11025733579/) · [Лесные тайны](https://yandex.by/maps/org/lesnyye_tayny/55770037829/)

Программа из семи кормлений хранится в приложении как датированный снимок. Напоминание устанавливается при сохранении события пользователем в системном календаре. [Опубликованная программа](https://animal-park.by/dopolnitelnyie-uslugi/pokazatelnoe-kormlenie.html)

Для показа из корня репозитория запустите `python -m http.server 8138 --bind 0.0.0.0 --directory public/demo`. Готовая сборка включена в эту ветку. На компьютере откройте `http://127.0.0.1:8138/?view=3d`. На телефоне в той же Wi-Fi-сети замените `127.0.0.1` локальным адресом компьютера. Брандмауэр должен разрешать вход на этот порт в частной сети. При первом знакомстве обычная ссылка открывает сцену Godot в совместимом браузере. При экономии трафика или медленном соединении 3D можно выбрать вручную. Кнопка «Лёгкая версия» возвращает к иллюстрированной сцене. Встреча использует WebGL 2, объём движка и сцены вместе около 80 МБ до сетевого сжатия.

1. Поднесите яблоко к лапам, дождитесь, пока Ричи его съест, и подтвердите имя. Через нижнюю вкладку можно уйти в парк и вернуться к анимации.
2. После знакомства выберите миску и яблоко, чтобы снова покормить малыша в 3D. Сытость начисляется по завершении еды. В домике также доступны купель, лежанка и сундук. Выигрыш даёт 5 листьев и 10 опыта. На 5 листьев можно купить плетёный мяч. Стадии взросления и тестовый купон привязаны к уровню.
3. Откройте **Парк → Я в парке → Кормления**. Выберите дату, найдите вольер № 36 или сохраните напоминание в календарь телефона. В каталоге хранится локальный снимок 116 видов с фотографиями. Официальная касса открывается отдельно. Демонстрационный купон действует только в тестовом расчёте.

Исходная редактируемая 3D-сцена находится в `Godot/Scenes/Levels/FirstMeeting.tscn`. В Godot 4.7.2 с экспортными шаблонами выполните из каталога Godot `godot --headless --import`, затем `godot --headless --export-release Web`. Остальные сцены демонстрационной игры и путеводитель находятся в `public/demo`. Профиль и покупки хранятся на устройстве в пределах адреса приложения.

Сборка оболочки выполняется командой `npm run build`. Маршрут `/` открывает игру, `/guide` — прежнюю главную модуля карт, `/calendar` — программу кормлений с выбором даты, карты и вида. Браузерный тест запускается командой `node scripts/check-demo.cjs http://127.0.0.1:8138/` с доступным для Node модулем Playwright и установленным Chromium. Сквозная проверка настоящей сцены Godot от первого яблока до второго кормления выполняется командой `node scripts/check-godot-feeding.cjs`. При использовании другого исполняемого файла Chromium укажите `BROWSER_EXE`.

Модуль карт для ООО «Парк Животных». Стек: Vite, React, TypeScript, Capacitor (мобильные), Electron (десктоп), Leaflet.

## Стек

- **Vite 7** — сборка
- **React 18** + **TypeScript**
- **Tailwind CSS**
- **Leaflet** + **react-leaflet** — карты
- **Capacitor 8** — Android и iOS
- **Electron 37** — Windows, macOS, Linux

## Запуск

### Веб / Dev

```bash
npm install
npm run dev
```

### Electron (десктоп)

```bash
npm run electron:dev
```

Сначала должен быть запущен Vite (`npm run dev`). Либо `electron:dev` сам поднимет Vite.

### Capacitor (мобильные)

```bash
# Добавить платформы (один раз)
npm run cap:add:android
npm run cap:add:ios   # только на macOS

# Сборка и синхронизация
npm run cap:sync

# Открыть в Android Studio / Xcode
npm run cap:open:android
npm run cap:open:ios
```

## Сборка

```bash
npm run build           # веб
npm run electron:build  # Electron
npm run build:win       # Windows
npm run build:mac       # macOS
npm run build:linux     # Linux
```
