# Домик у тропы · Парк животных

Мобильная игра с енотом и отдельным путеводителем. Активная разработка — ветка `2.0`. [Проверочное ТЗ](specs/animal-park/TZ.md) · [кадры из сборки](docs/showcase/review/index.html) · [происхождение карты](specs/animal-park/maps/alignment.md).

## Локальный запуск

На подготовленном Windows-компьютере дважды нажмите [Start-Demo.cmd](Start-Demo.cmd). Он откроет действующую вкладку или поднимет сервер и откроет браузер. При первом запуске сервера оставьте его окно открытым до конца показа.

Для полного показа с семейным профилем используйте Node.js 24 и установленный Chromium с WebGL2. Из корня проекта выполните:

```shell
npm ci
npm run dev -- --host 127.0.0.1 --port 8168 --strictPort
```

[Игра](http://127.0.0.1:8168/demo/index.html) · [парк](http://127.0.0.1:8168/demo/index.html#park) · [редактор привязки и контуров](http://127.0.0.1:8168/demo/align.html). Сохранения гостя зависят от адреса браузера, включая порт. Служебное редактирование геометрии доступно только через локальный dev-сервер. Оригинал ручной подгонки растра сохраняется отдельно от файла контуров. Сервер семейных профилей работает в Vite dev и preview; данные лежат вне публикуемой директории. Переменная `ANIMAL_PARK_FAMILY_DIR` позволяет выбрать другой закрытый каталог. Удалённый вход на открытом HTTP отключён.

### Что посмотреть

[Сводка проекта с кадрами и открытыми вопросами](docs/showcase/project-status.html)

[Запустить на Windows](Start-Demo.cmd) · [Первая встреча, покупка лежанки и сон в Godot](docs/showcase/first-room/README.md)

1. Первая встреча → перенести яблоко к лапам → имя → дом Godot. При экономии трафика доступен облегчённый режим. Повторный вход с той же вкладки открывает сохранение.
2. Через предметы комнаты доступны кормление, купание, сон, сундук с тремя играми и лавка. Проверьте примерку, отмену, покупку за листья, замену лежанки диваном, возвращение из парка.
3. Во вкладке «Парк» откройте кафе из информации для посетителей и вернитесь стрелкой. На единой карте выберите вольер; там, где обведена граница, доступно касание внутри площади. Остальные места имеют точку или связь с зоной. Внешние ссылки Яндекса различают место и проверенный гостевой подход.
4. Через профиль можно создать семейный аккаунт, отдельно сохранить енота и восстановить его в другой сессии этого сервера. Тест билета не создаёт реальный заказ.

### Исходники и проверки

Сцены находятся в [Godot/Scenes](Godot/Scenes). В Godot 4.7.2 с шаблоном Web откройте `Godot/project.godot`, затем используйте экспорт Web. Браузерный комплект Godot хранится в `public/demo/meeting3d`. Путеводитель использует исходный модуль карты, Leaflet, локальный растр и справочные данные. Меню находится в `src/park-menu.tsx` и `src/components/ui/menu-vertical.tsx`.

`npm run build` собирает React-оболочку и веб-ресурсы. Тесты браузера используют Playwright и Chromium (исполняемый файл можно указать в `BROWSER_EXE`). Точка входа при запущенном Vite — `http://127.0.0.1:8168/demo/index.html`. Команды и критерии приведены в [ТЗ](specs/animal-park/TZ.md). Для самостоятельной проверки семейного аккаунта используйте `node scripts/check-family.cjs`: тест создаёт изолированную временную базу и два браузерных контекста.

## Исходный модуль

Модуль карт для ООО «Парк Животных». Стек: Vite, React, TypeScript, Capacitor (мобильные), Electron (десктоп), Leaflet.

## Стек

- **Vite 7** — сборка
- **React 18** + **TypeScript**
- **Tailwind CSS**
- **Leaflet** + **react-leaflet** — карты
- **Capacitor 8** — Android и iOS
- **Electron 37** — Windows, macOS, Linux

## Запуск

### Веб / Dev

```bash
npm install
npm run dev
```

### Electron (десктоп)

```bash
npm run electron:dev
```

Сначала должен быть запущен Vite (`npm run dev`). Либо `electron:dev` сам поднимет Vite.

### Capacitor (мобильные)

```bash
# Добавить платформы (один раз)
npm run cap:add:android
npm run cap:add:ios   # только на macOS

# Сборка и синхронизация
npm run cap:sync

# Открыть в Android Studio / Xcode
npm run cap:open:android
npm run cap:open:ios
```

## Сборка

```bash
npm run build           # веб
npm run electron:build  # Electron
npm run build:win       # Windows
npm run build:mac       # macOS
npm run build:linux     # Linux
```
