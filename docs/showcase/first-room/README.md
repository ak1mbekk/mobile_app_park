# Домик у тропы

Откройте `Godot/project.godot`. В редакторе выберите [FirstMeeting.tscn](../../../Godot/Scenes/Levels/FirstMeeting.tscn) и нажмите F6. Окно, скамья, корзинка, коврик, яблоко и енот выбираются непосредственно в дереве уровня. Для изменения одного предмета достаточно выбрать его и передвинуть. Камера рассчитана на портретный экран.

| Кадр из Godot | Что проверить в игре |
| --- | --- |
| [Первая встреча](first-meeting.png) | Протяните яблоко с пола к лапам. При промахе оно возвращается на место. После еды появляется поле имени. |
| [После имени](bed-invitation.png) | Лежанка ещё в лавке, купелью уже можно пользоваться. Кнопка «Сыграть» открывает «Найди пару». |
| [После покупки](bed-placed.png) | Первая завершённая игра в пары даёт 5 листиков. Кнопка «Купить лежанку за 5 листиков» размещает лежанку в доме. Купленная лежанка сохраняется при следующем запуске. |
| [Движение к мебели и пробуждение](sleep-movement.mp4) | Первый эпизод показывает подход к лежанке, сон и возвращение на коврик. Второй показывает прыжок на диван. Это запись движка с портретной камерой, 30 кадров/с. |
| [Сон крупным планом](curled.png) | Видны закрытые веки, поджатые лапы и хвост у морды. Во время сна продолжается дыхание. |

Окружение разделено на [сцены предметов](../../../Godot/Scenes/Environment/TrailHouse), [интерактивные предметы](../../../Godot/Scenes/Props/Interactive) и [домашние занятия](../../../Godot/Scenes/Home). Положение мебели для сна меняется в [Bedroom.tscn](../../../Godot/Scenes/Home/Bedroom.tscn). Полная библиотека предметов, включая обстановку последующих этапов, перечислена в [каталоге моделей](../../../models/README.md).

[Экран загрузки в браузере](opening.png) показывает Ричи у порога домика. Логотип взят из [официальной графики парка](https://animal-park.by/parkzhivotnyix.webp). При известном размере данных полоска показывает долю загрузки Godot. На готовой сцене заставка исчезает. В Android системный старт показывает знак парка перед игровым экраном. Для iOS портрет подключён к LaunchScreen.
